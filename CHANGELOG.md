# Changelog

## 0.1.0 — 2026-10-18

- Initial independent Qt Widgets component library, extracted from original self-painted glass controls.
- PyQt6/PySide6 binding selection, per-host light/dark/system appearance, 0–60% transparency, custom accent and motion switch.
- Cached material surfaces, native-signal buttons, adaptive segmented navigation and explicitly themed list popups.
- Interactive neutral gallery, minimal/existing-window examples, bilingual documentation, dependency notices and regression checks.
